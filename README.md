# PYTHON: ORIENTADO A OBJETOS OOP

> Aulas do Curso em Vídeo com total foco em POO/OOP/OOAD Python

---

## Etapas do Aprendizado

- **Mundo 1** Embasamento: de onde veio, para que serve, vantagens de uso, entendendo o paradigma
- **Mundo 2** Fundamentos: Classe, Objeto, Atributos, Métodos, Estado, Instância, Visiblidade, 4 pilares
- **Mundo 3** Pilares: Abstração, Encapsulamento, Herança, Polimorfismo
- **Mundo 4** Conceitos: Getters, Setters, Self e Supper, Dunder Methods, Associação, Agregação, Composição
- **Mundo 5** Bancos de Dados: Acesso a bases locais, SQLite3, ORM (Object-Relational Mapper)
